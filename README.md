# AI Roleplay Guides

Plain guides to AI roleplay and interactive stories, written by the team behind [Lunafic](https://lunafic.ai), an AI roleplay app.

Site: https://lunafic-ai.github.io/roleplay/

This repository holds only the public guide pages (Jekyll on GitHub Pages). Guides live in `_guides/`. Each guide shows the date its facts were last checked.

Corrections are welcome: open an issue.
